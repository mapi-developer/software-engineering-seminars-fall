# Software Engineering 2026 — Seminars (C# Solutions)

This repository contains the C# solution developed for the Software Engineering 2026 course seminars. It provides sample implementations, exercises, and reference code used during the course.

**Overview**
- **Purpose:** Course seminar solutions and example projects implemented in C#.
- **Language:** C# (dotnet CLI / .NET 8+ recommended)
- **Contents:** Solution(s), project folders, and tests for seminar assignments.

**Getting Started**
- **Prerequisites:** Install the .NET SDK (8.0 or later). Verify with `dotnet --version`.
- **Build:** `dotnet build`
- **Run (example):** `dotnet run --project <ProjectPath>`
- **Tests:** `dotnet test`

**Repository Structure**
- `src/` — primary seminar projects and solutions
- `tests/` — unit and integration tests
- `docs/` — supplemental notes and instructions
